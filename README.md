# Weather App

> A lightweight weather application for exploring location-based weather data and a clean responsive frontend experience.

**Repository:** `mohitkumar402/weatherapp`

---

## What it does

- Fetches and displays weather information
- Presents location-based conditions in a simple UI
- Uses a responsive interface for desktop and mobile screens
- Demonstrates API-driven frontend development

## Run locally

```bash
git clone https://github.com/mohitkumar402/weatherapp.git
cd weatherapp
npm install
npm start
```

> Check the project source for the required weather API configuration before running the application.

## Why this project

A focused frontend project demonstrating API integration, asynchronous data handling, and responsive UI development.
